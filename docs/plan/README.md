# 单舞蹈执行计划

本demo面向OpenSprite，训练目标为LAFAN `dance2_subject1`，源长225.66秒。

1. 从官方机器人资产生成31关节、32 link模型，核对轴、惯量、碰撞、限位和effort。
2. 使用Geno人体资产和OpenSprite表面采样，训练UMR对应关系，优化原始BVH并转换为50Hz动作库。
3. 从零训练actor、世界模型、critic和成本head。当前配方及八小时累计预算见[主README](../../README.md)。
4. 每小时检查预算、进程、有限值、真实误差、模型误差和完整动作表现。故障恢复保留原预算。
5. 发布单舞蹈原始数据、对应资产、动作库、快照和视频。复现入口见[复现说明](../reproduce.md)。

复核重点为机器人适配、动作时间轴、真实与想象执行器一致性、模型梯度、完整轨迹评分和依赖独立性。当前视频包含失败后继续的真实仿真，未达到完整跟踪成功。
