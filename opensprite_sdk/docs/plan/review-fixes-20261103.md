# SDK 交付审查修复

本轮处理交付审查报告中的3项P1、3项P2和发行检查P3。原始反例保留在本地 `outputs/review-20261103/`，原生力矩/退出反例位于 `outputs/review-hardware/`。这些目录不参与发布。

## Unitree SDK 接口依据

研究基准是 `.reference/unitree_sdk2_python` 固定版本 `814556d15970dd2ecf1c9984e845ca02ab07e206` 的 `core/channel.py` 及 G1 low-level例程。保留 `ChannelFactoryInitialize`、Publisher/Subscriber、Init/Write/Read/Close和q/dq/Kp/Kd/tau的使用习惯。发布状态和周期发送命令是异步操作，不能要求控制程序与内部接收循环逐帧同步。

`Write`成功表示通信层接受消息，不表示订阅者已经执行。慢诊断消费者不得进入控制发布的同步等待链。默认采用有界latest语义；这与使用DDS消息的习惯相符，但本SDK仍使用自己的31关节消息和本地通信，不宣称DDS二进制互通，也不复用其他机器人的关节顺序或参数。

## 分工与修复原则

| 问题 | 修复单元 | 回归重点 |
|---|---|---|
| 故障总线中断全身失能 | native agent，主agent复核 | 健康总线继续收到失能；报告保留失败及逐电机验证 |
| 非脚踝完整关节力矩越界 | native agent，hardware agent与主agent复核 | 直接关节、传动比、头部耦合、量化后和已保持PD |
| 异步来源状态被误拒及重签 | hardware agent，主agent复核 | 50Hz跨进程旧帧仍合法；真实来源seq、epoch、年龄保持 |
| 慢订阅者阻塞发布 | channel agent，hardware agent复核 | 暂停诊断进程，健康读者继续，队列有界，最终状态可达 |
| 失能序号高水位未提交 | 主agent，team复核 | stop seq100后拒绝active seq2，reset才更换控制epoch |
| 固定非零延迟被忽略 | 主agent，team复核 | min=max为1和3、hold=1、reset前后真实命令延迟 |
| 本地标定进入搬迁副本 | 主agent，team复核 | 真实发行检查排除local.json；源码归档保留忽略规则 |

硬件来源快照采用独立有界缓存，来源actor观测的关节60ms/IMU30ms上限与执行器当前反馈的脚踝10ms/其他60ms/IMU30ms上限分别检查。不能用新聚合包替旧观测续命，也不能发送时改写来源序号。

保留内置电机PD。非脚踝完整关节力矩越界采用明确拒绝，不能只限制前馈力矩或悄悄改成全身前馈控制。MuJoCo和主机脚踝PD继续按各自配置做力矩饱和，差异写入接口文档。

原生失能清理必须逐电机和总线尽力完成，错误在最后聚合。某条总线失败不能跳过健康总线；未确认全部失能时不能报告成功。测试使用本地socket和故障注入，不打开CAN设备。

## 验收

先逐单元运行原始反例和新增回归，再交叉审查，最后执行全套Python、真实C++、独立搬迁与源码归档检查。用已有bundle做完整225.66秒CPU sim2sim，保留首次失败和未评分后续轨迹。现有训练配置、固定训练分支及预算保持原状。

实机边界不变：本轮不操作电机，Jetson ARM64、实际USB IMU协议、CAN适配器及上电验收仍需设备实测。修复软件反例不等同于完成真机认证。

## 修复后结果

0.1.1已完成上述7类问题修复，并由实现者之外的team成员交叉复核。199项Python测试、完整原生构建和3项CTest通过。真实C++回归覆盖生成的31电机配置、故障首总线及其余3条健康总线各电机三轮失能；故障报告仍为未通过。原先关节1Nm却接受约1.96Nm的配置反例现在明确拒绝。

异步客户端跨20ms来源仍可接受，wire保留原source序号；暂停普通SDK诊断进程时200次发布和健康订阅者正常。独立wheel/源码搬迁及双进程失能退出通过，local.json哨兵文件没有进入发行副本，源码归档包含忽略规则。

同一舞蹈bundle完整运行11283转移、225.66秒，首次失败仍为193.76秒。与修复前默认仿真逐项比较，qpos/qvel/动作/目标和评分标记全部一致。该结果只证明默认仿真没有被这些修复改变。

现有跨进程桥接可能额外排队一个50Hz周期；这一延迟没有在本轮被消除，直接监督入口不经过该桥接。原生力矩守护基于当前采样和主机发送顺序，不承诺跨总线实际到达顺序或采样间连续机械力矩保证。实机验收边界保持不变。
